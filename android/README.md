## Android 平板遥控台

平板使用 Android 8.0 或以上，并支持经典蓝牙串口（SPP）。在系统蓝牙设置中配对车载模块，再在遥控台点「连接设备」选中它。Android 12 及以上首次连接时允许「附近的设备」。

- 底盘页允许双指分别控制平移和旋转。首版平移指令上限 100 mm/s，旋转上限 45 °/s；松开其中一个摇杆只清零对应轴。
- 机械臂页按住点动，松开保持最后目标。进入此页清空底盘速度。顶部停止键与切换模式均发送车端已有的 `S` 指令。
- 半自动循迹页进入时先停车，点「启动循迹」后持续发送 `A`。到线或丢线时由车端停车；再次启动前先点「停止循迹」。切页、顶部停止或退到后台都会撤销运行指令。
- App 使用同一条 RFCOMM 连接串行发送 ASCII 行，按下或松手立即安排发送，保持时每 50 ms 更新。车端遥控超时需留出无线链路和 Android 调度抖动余量；断链、后台恢复或重连后，重新触摸才开始操作。平板显示的是蓝牙连接状态，车端协议没有动作执行回执。

### 构建与联调

在 Android Studio 打开本目录，使用 Android SDK 35 和 JDK 17 或兼容版本。执行 `gradlew.bat assembleDebug` 后，APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

架空车轮后连接平板，确认首次连接时车保持静止，再依次检查双指平移与旋转、单侧松手、按住前进时切换机械臂、夹爪松键保持和断联停车。最后确认重连后底盘与机械臂均等待新的触摸。
